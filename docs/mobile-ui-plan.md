# 手机端 UI 内容与功能清单

状态：已实现。依据手机首页参考图重排页面，加入日间高对比、夜间主题和独立 Dashboard；下列为当前功能说明。

## 目标

比赛中快速看清本船位置、当前速度和短期预估位置；起航和分析各有独立入口。
底部导航固定为：**比赛｜起航｜战术｜更多**。
本轮优先整理已有功能，不继续向主屏叠加数据卡片。

## 1. 比赛：默认首页

### 常驻内容

- 顶部紧凑两行：赛事/场次、本船选择、上报年龄，以及 Dashboard 和日间/夜间按钮。
- 地图占主要空间，竖屏目标约占可用内容区的三分之二。
- 显示本船、其他船、起航线和航标；本船突出，其他船默认不展开文字标签。
- 本船预测路径上标出「30秒」「1分钟」两个位置点。
- 底部单行仪表：当前船速（kn）、30秒航程（米）、1分钟航程（米）。
- 地图快捷操作：回到全场、图层入口。

### 按需展开

- 点本船名称：选择或切换本船。
- 轻点船只：设为本船，顶部显示船名和数据年龄，仪表显示速度；不默认铺满地图标签。
- 打开 Dashboard 查看位置详情：距起航线、距1标、向1标推进。
- 图层：轨迹、其他船名、其他船预判、距离网格、本船预判、1标参考线、起航线详情。当前页面保留图层状态。
- 选船后自动跟随本船；定位按钮切换本船与全场，拖动退出跟随，双击回到全场。

### 主屏信息规则

- 30秒和1分钟是从最新上报位置起算的外推，数据年龄与结果一起可见。
- 有效风信息用小型方向/风速提示；过期时标明状态，不当成当前风。
- 正常状态用简短标识，异常才出现明显提示；详细算法说明通过点开查看。
- 本船未选择时只给一个主操作：「选择我的船」。

## 2. 起航：同一张地图，切换仪表

### 常驻内容

- 本船、起航线和接近轨迹。
- 三个主读数：距手动起航、预计到线、预计早/晚多少秒。
- 到线估算不可用时，在原位置显示短原因，不用旧数值占位。
- 起航仪表替换比赛仪表，二者不叠加。

### 起航设置

- 按现场信号进行5分钟、4分钟、1分钟校准。
- 提前1秒、延后1秒、清除校准。
- 确认起航方向。
- 收起设置后，计时继续；用户主动切回比赛页，不自动猜测是否完成起航。

预计到线使用近期对地轨迹，早/晚相对手动校准时刻；页面不显示官方抢航判定。

## 3. 战术：记录、结论、依据

### 首屏内容

- 记录状态：未记录/记录中/已完成，以及记录时长。
- 一个主操作：开始记录，记录中切换成结束并分析。
- 最新样本结论，例如「上轮样本：左侧推进较快」。
- 结论旁显示样本范围、生成时间和证据强度。
- 数据不足时显示「证据不足」，不强行给出左右侧选择。

### 二级内容

- 记录设置：首个迎风段/第一圈/第一场；确认迎风参考方向。
- 查看依据：左右推进差、可比时间窗、样本船数、数据覆盖、历史风向变化。
- AI解读：数据依据、下一同方向航段的观察建议、需要重新判断的条件。
- 历史报告与摘要导出。

### 来源与适用范围

- 区分「本地统计」「AI解读」「AI未配置」，不以统一的AI标识混淆来源。
- 本地统计默认给短结论；完整报告点开后阅读。
- 整圈/整场目前只比较其中可匹配的迎风片段，范围开始和结束由用户标记。
- 跨场报告保留原场次名称和时间，并标注历史；不自动当作当前航线建议。
- 比赛地图不叠加长篇战术建议；当前/历史报告摘要放在 Dashboard，完整内容到战术页查看。

## 4. 更多：低频操作

- 赛事、组别、场次选择。
- 船队列表及航标详情。
- 显示设置与单位说明。
- 手动水流假设放在高级设置，标注其不是实测数据。
- AI服务连接状态、使用说明、数据与隐私说明。
- 默认日间高对比主题，顶部一键切换夜间，选择保存在当前浏览器；密钥不放在手机页面输入。

## 5. Dashboard：集中查看全部读数

- 顶部四格按钮和更多页均可进入；按航行、比赛位置、起航、风与水流、船队与连接、战术分析分组。
- 航行：本船数据年龄、当前船速、30秒及1分钟航程和预判条件。
- 位置：距有限起航线段、距1标、向1标推进速度；只使用10秒内的有效位置。
- 起航：手动时刻、预计到线和早晚差；缺少条件时说明原因。离开地图后倒计时继续刷新。
- 风与水流：风力仪来向、风速、上报年龄；风数据超过10秒标为过期，水流始终标注手动假设。
- 船队：30秒内有效位置上报数/船队总数，以及快照刷新或失败状态；并非船员在线人数。
- 战术：当前记录范围与时长、选中的历史报告（无选择时最近一份）、左右侧比较、依据、记录场次与时间、AI配置状态。
- 跨场次报告明确提示不能直接用于当前场次。AI未配置、单文件模式与本地统计分开说明。
- 底部仍可随时回比赛、起航、战术和更多；总览可纵向滚动，不把所有内容硬塞进一屏。

## 视觉与交互要求

- 一屏只有一组主要数字；常规仪表与起航仪表互相替换。
- 常用按钮目标高度48px；为窄屏保留足够间距。
- 核心读数采用大号数字，单位紧邻数值，不让小数位或长度变化挤动布局。
- 本船、其他船、航标用稳定配色与形状区分；状态同时提供文字，不能只靠颜色判断。
- 收起大段说明、完整船表和历史报告；需要解释时在相关读数附近点开。
- 小范围设置用底部面板；战术正文使用独立可滚动页面。
- 地图交互不被仪表覆盖；底部导航始终可达，适配安全区与横屏。
- 不凭空加入官方名次、自动绕标、胜率百分比或“最优航线”提示。

## 地图与验收边界

地图使用赛事零距离官网同一套 SF-TrajX `vector` 底图，保留实际海岸与道路。
原官方 `live2` 数据源、1秒轮询、设备时间与速度字段保持不变；新UI和Dashboard不生成或替换位置数据。
地图提供最后设备上报时间；官方停止上报时明确显示旧数据，不把接口请求时间当作设备测量时间。
底图只请求可见区域并限制缓存；加载失败会提示，不悄悄替换成其他供应商或模拟地图。
默认底图并非海图水深或卫星图；更多页可直接打开该场官网地图核对。
日间主题针对强光阅读增加对比与字号，实际阳光、屏幕亮度和湿手操作仍需在设备上试用。

验收覆盖320px、390px竖屏和手机横屏：无横向溢出、主要操作可见、地图标签避开固定浮层；
并检查未选船、数据过期、断网、起航未校准、分析不足、AI未配置和历史跨场等状态。
